# To-Do List Application

A responsive To-Do List web application developed as part of the CODSOFT Frontend Development Internship – Task 2.

## About the Project

This application helps users organize and manage their daily tasks through a simple and user-friendly interface.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks by status
- Save tasks using browser Local Storage
- Responsive user interface
- Theme customization

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the VS Code Live Server extension.
